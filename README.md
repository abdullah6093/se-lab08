# Lab 08 - Recursion

SE-314 Software Construction.

- `FileSearch` - recursive file search (multiple files, count, `-i` for case-insensitive)
- `Permutations` - string permutations, recursive and iterative (`-nodup`, `-compare`)

Run tests: `./run-tests.sh`

Examples:
```
java -cp bin recursion.FileSearch -i sample notes.txt todo.txt
java -cp bin recursion.Permutations abc
java -cp bin recursion.Permutations -compare
```
